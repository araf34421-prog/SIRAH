# SIRAH
SIRAH (Sistem Informasi Rencana Hafalan) adalah website untuk membantu perencanaan dan pengelolaan program hafalan santri di Surau Tahfizh Firdaus. Sistem ini mendukung pengaturan target, jadwal hafalan, pencatatan setoran, pemantauan perkembangan, serta penyusunan laporan agar kegiatan tahfizh lebih terstruktur dan efisien.
